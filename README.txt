1. Install Node.js + SQL Server (TCP/IP enabled, mixed auth).
2. Edit dbconfig.json if needed. Database + all tables are created/upgraded automatically (existing data is kept).
3. npm install
4. npm start        (installer: npm run dist)
Default login: admin / admin  -> change it in Users. Open a shift in "Cash Register" before selling.
Business info, VAT, bill layout, loyalty and colors: Settings (live bill preview).
